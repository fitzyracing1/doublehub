doublehub · free, open source

Turn your service into a GitHub App install link in 2 minutes.

For companies and orgs that want GitHub users to connect to their service. Fill in one form, and you get your own GitHub App, an install link and an "Install on GitHub" badge. No backend needed.

Make my GitHub AppTry the sign-in

How it works

Three steps. The app is created on your own GitHub account.

1

Describe your service

Name, URL and only the permissions you need.

2

GitHub creates the app

One click sends you to GitHub, which creates the app on your account or org.

3

Share the install link

Put the link or badge on your site so users can install your app.

Security: visitors sign in with GitHub, then approve doublehub separately on each site (revocable any time), and every call that leaves needs their OK.
